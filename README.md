# CAI ULEAM - Sitio web

Proyecto estático HTML preparado para publicarse en Netlify.

## Estructura

- `index.html` — página principal.
- `netlify.toml` — configuración de publicación en Netlify.
- `.gitignore` — archivos locales que no deben subirse.
- `.github/workflows/deploy.yml` — flujo opcional para GitHub Pages.

## Publicar en Netlify

1. En Netlify, entra a **Add new project** / **Upload your project files**.
2. Sube esta carpeta completa o un ZIP de esta carpeta.
3. Netlify publicará `index.html` como página principal.

## Nota sobre imágenes

El HTML utiliza dos imágenes locales: `Image uleam.jpeg` y `image_81729f.png..jpeg`.
Si deseas que esos logotipos aparezcan al publicar, coloca esos dos archivos en esta misma carpeta antes de subirla a Netlify.
